# PLAN: Packout (bulk export for Quip sites)

Ordered so the core tool works end to end against the mock as early as possible (and shows on the
GitHub Pages preview through the "sample site" demo), then widens. Module names and the architecture
are in `CLAUDE.md`; the look is in `DESIGN.md`. Every task ends green on `npm test` and `npm run build`.
AC numbers refer to SPEC.md section 6.

## 1. Foundation

- [ ] **Design foundation.** Finish `src/styles/tokens.css` and add `src/styles/components.css` (imported in `Base.astro`) with the button, secondary button, input, tick-box radio, notice strip, ledger table and the waybill label from DESIGN.md: label stock, hard offset shadow, perforated tear line with two CSS-circle notches, packing-tape progress strip, FRAGILE sticker, PACKED stamp. - [ ] **Synthetic mock site (fixtures).** `src/mock/fixtures.ts`, clearly labelled SYNTHETIC: user `Dana Example`; private folder with 3 folders incl. 1 nested subfolder (4 folders counted), 12 documents, 3 spreadsheets, 1 document in two folders, 1 thread with 120 comments, 4 internal links in document HTML (3 to exported threads, 1 to a thread id that is not in the site), 2 images (`/blob/<threadId>/<blobId>` refs). Check: `test/fixtures.test.ts` asserts these counts directly from the fixture data.
- [ ] **Mock Quip API.** `src/mock/mockQuip.ts`: `createMockQuipFetch({ fail503Times?, onRequest? })` returns a `fetch`-compatible function serving `GET /1/users/current`, `/1/folders/?ids=`, `/1/threads/?ids=`, `/1/threads/{id}`, `/1/threads/{id}/messages?count=100&cursor=` (cursor paging, 100 per page), `/1/threads/{id}/export/docx` and `/export/xlsx` (minimal valid DOCX/XLSX zips built with fflate), `/1/blob/{threadId}/{blobId}` (tiny PNG bytes). - [ ] **Rate limiter.** `src/lib/ratelimit.ts`: `RateLimiter({ perMinute: 45, perHour: 700, clock })` with an injectable clock (`now()`, `sleep(ms)`) using sliding windows; `withRetry` treating 503 and 429 as throttling with exponential backoff (base 2 s, max 5 min, honour `Retry-After`), other 5xx retried 3 times, 4xx fails. - [ ] **Quip client.** `src/lib/quip/client.ts` + `types.ts`: `QuipClient({ fetch, apiBase, token, limiter })` with `currentUser()`, `folders(ids)` (batched, 10 ids per call), `threads(ids)` (batched), `messagesAll(threadId)` (follows the cursor), `exportDocx(id)`, `exportXlsx(id)`, `blob(threadId, blobId)`. - [ ] **Dry run (crawl + inventory).** `src/lib/crawl.ts`: `dryRun(client)` walks private, shared and starred folders breadth-first (dedupe by id), loads thread metadata + HTML in batches, counts folders, documents, spreadsheets, multi-folder threads, internal links (resolved/unresolved via `src/lib/export/links.ts` `findQuipLinks`), comments (all threads when ≤ 50 threads, otherwise the first 50 as a sample, shown as "sampled"), unsupported types (slides, chat → "not exportable"). Check: `test/dryrun.test.ts` asserts exactly 4 folders, 12 docs, 3 sheets, 1 multi-folder, 4 links (1 unresolved), ≥ 120 comments, a duration > 0 and tier "free"/"site" as computed (AC3).

## 2. Thin end-to-end export

- [ ] **Paths and folder tree.** `src/lib/export/paths.ts`: safe file names (strip `/\:*?"<>|`, trim, max 120 chars, de-duplicate siblings with ` (2)`), primary path = first folder path in crawl order, other paths listed; `relativePath(from, to)`. Check: `test/paths.test.ts` incl. the multi-folder doc and a name collision.
- [ ] **Link rewriting.** `src/lib/export/links.ts`: `findQuipLinks(html, host)` matches `https://<host>/<threadId>…` and `/<threadId>/…` hrefs (Quip thread ids are 11–12 char alphanumerics; match against known ids, keep anchors); `rewriteLinks(html, fromPath, idToPath)` turns resolved links into relative paths and leaves others untouched; returns rows for `link-map.csv` (`source_thread_id, source_path, old_url, new_path, status`). Check: `test/links.test.ts`: 3 resolved, 1 unresolved, no output href contains the mock host for an exported thread (AC5).
- [ ] **Comments.** `src/lib/export/comments.ts`: inline "Comments" block appended to the document HTML (author, ISO timestamp, text, escaped), `comments.csv` rows (`thread_id, thread_title, comment_id, author, created_at, text`), and `src/lib/export/docx-appendix.ts` that unzips the DOCX with fflate and inserts a "Comments" heading plus one paragraph per comment before `<w:sectPr>`. Check: `test/comments.test.ts`: the 120-comment thread yields 120 CSV rows with author and timestamp; the patched DOCX unzips and `word/document.xml` contains the last comment text (AC4f).
- [ ] **Images.** `src/lib/export/images.ts`: find blob refs in HTML, fetch each once, store as `<doc folder>/<doc name>_files/<blobId>.<ext>`, rewrite `src` to that relative path. Check: `test/images.test.ts`: 2 images stored, HTML references them relatively, no `/blob/` URL left (AC4g).
- [ ] **ZIP writer.** `src/lib/export/zip.ts` on fflate `Zip` + `ZipPassThrough`/`ZipDeflate`: add files in order, emit chunks, start a new part when a part would pass `maxPartBytes` (default 1 GB, small in tests). In the browser, chunks become a `Blob` per part for download. Check: `test/zip.test.ts`: round-trip with `unzipSync`, and a 3-part split with `maxPartBytes` set tiny.
- [ ] **Manifest, index and README.** `src/lib/export/manifest.ts`: `manifest.csv` (columns `thread_id,title,type,primary_path,other_paths,owner,updated_at,comment_count,status`, RFC 4180 quoting via `src/lib/export/csv.ts`), offline `index.html` (styled inline in the Packout look, relative links to every item, a tick column), redirect stubs for other paths (`.html` with meta refresh + link). `src/lib/export/readme.ts`: `README.txt` with preset-specific import steps. Check: `test/manifest.test.ts`: one row per thread, both paths for the multi-folder doc (AC4d, AC6).
- [ ] **Export runner (Archive preset).** `src/lib/export/run.ts`: `runExport({ client, inventory, preset, limit, checkpoint, onProgress, signal })` per thread: HTML + comments + images + link rewrite, DOCX (+ appendix) for documents, XLSX + HTML for spreadsheets; then manifest, link-map, comments.csv, index, README, stubs; streams into the ZIP writer. Unsupported types get a placeholder `.txt` and status `not_exportable`. Check: `test/export.e2e.test.ts` unzips the result and asserts AC4 a–g, AC5 and AC6, and that every href in `index.html` resolves to a file in the ZIP.
- [ ] **Home page tool, first working version.** `src/components/ExportTool.tsx` (Preact island, `client:load` on `/`): host choice (quip.com / company domain), token field (password type, show toggle, link to the how-to), "Free dry run" primary button, the waybill result, "Export 20 for free" and "Export all N – price" buttons, packing-tape progress, PACKED done state with download link(s), STOPPED error state with what to do. A "Try it on a sample site" text link runs the same flow against the in-browser mock (labelled "sample data, not your Quip"), so the Pages preview works without a relay. ## 3. Money and safety

- [ ] **Free cap.** In `run.ts` and the tool: without a valid licence, exports above 20 threads are refused with a clear message naming the tier and price; the user picks up to 20 documents (tick boxes in a ledger) for the free export. Check: `test/cap.test.ts`: 21 threads without licence → `LicenceRequiredError` with tier and price; 20 → ZIP (AC9).
- [ ] **Licence tokens.** `src/lib/license.ts` (shared by worker and client, Web Crypto only): `signLicence(claims, secret)` / `verifyLicence(token, secret, { host, userId, now })` with claims `{ tier, cap, host, uid, exp }`, base64url payload + HMAC-SHA256, constant-time compare. The client cannot hold the secret, so it sends the licence to the relay `POST /license/verify` and enforces the returned cap. Check: `test/license.test.ts`: valid unlocks; tampered, expired, wrong host and wrong user are rejected (AC10).
- [ ] **Relay worker.** `worker/relay.ts` (`export default { fetch(request, env) }`) + `worker/wrangler.toml` with **no** KV/R2/D1/cache bindings: CORS preflight; `/api/*` forwards to `https://<X-Quip-Host>/…` only when the host is in `QUIP_HOST_ALLOWLIST` (else 400), passes `Authorization` through, strips cookies, streams the body back, `Cache-Control: no-store`; logs nothing but method, path template and status. Check: `test/relay.test.ts`: non-allowlisted host → 400; forwarded request reaches a stubbed `fetch` with the token; captured `console.*` output contains neither the token nor body text (AC11); a static scan asserts `wrangler.toml` has no `kv_namespaces`, `r2_buckets`, `d1_databases`.
- [ ] **Stripe Checkout (test mode).** In the worker: `POST /checkout` `{ tier, host, uid }` creates a Checkout Session via `fetch` to the Stripe REST API (form-encoded, `STRIPE_PRICE_SITE`/`STRIPE_PRICE_LARGE`, `tax_id_collection[enabled]=true`, `invoice_creation[enabled]=true`, success URL back to `/?session_id={CHECKOUT_SESSION_ID}`); `GET /license?session_id=` retrieves the session, requires `payment_status=paid`, returns a 90-day licence. Client stores the licence in `sessionStorage` only (never the Quip token unless the user opts in for resume). Check: `test/checkout.test.ts` with mocked Stripe responses: unpaid → 402, paid → verifiable licence with the session's tier, host and uid.
- [ ] **Token hygiene.** Check: `test/token-hygiene.test.ts` runs the full mock export with a recognisable token, then greps every file in the ZIP, every IndexedDB record (fake-indexeddb), `localStorage` and every analytics call for the token; none contain it; no request URL contains it (AC12).

## 4. Resume and presets

- [ ] **Checkpoint and resume.** `src/lib/checkpoint.ts` on IndexedDB (`fake-indexeddb/auto` in tests): run record `{ runId, host, uid, preset, threadStatus, createdAt }` and per-thread output files; never the token. `runExport` skips threads marked done and re-reads their files from the store. The tool offers "Resume the export from <date>" when a run exists. Check: `test/resume.test.ts`: abort via `AbortSignal` after 6 threads, build a new client + runner from the checkpoint, finish; the mock's `onRequest` log shows no second fetch for the first 6 threads; final ZIP equals the uninterrupted one in file list (AC8).
- [ ] **Destination presets.** `src/lib/export/presets.ts`: SharePoint (DOCX/XLSX + `.url` shortcuts for other paths, HTML kept only in `_archive/`), Google Drive (DOCX/XLSX, link-map for later fixing), Notion (Markdown via turndown with relative `.md` links + images, no DOCX), Archive (everything). Preset picker in the tool as four tick boxes. Check: `test/presets.test.ts`: file extensions per preset match SPEC, and `README.txt` contains the preset's own steps (AC13).
